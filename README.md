This project is an end-to-end SQL data analytics case study that transforms raw data into actionable business intelligence using industry-standard warehousing and analysis workflows. It begins with building a structured data warehouse, then moves through core analytical techniques such as tracking changes over time, calculating cumulative growth, and benchmarking performance against targets. Building on this foundation, the project applies more advanced techniques like part-to-whole analysis and data segmentation — turning raw measures into meaningful dimensions to categorize customers and products. It culminates in professional-grade customer insights and product performance reports, delivered as database views for easy stakeholder access, making this a polished, end-to-end example of a professional data analyst portfolio project.
